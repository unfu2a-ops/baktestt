# Front-End Portfolio

مینی‌پروژه پورتفولیوی شخصی با HTML + CSS + JavaScript

## اجرا
فقط فایل `index.html` را در مرورگر باز کنید.

## ساختار
- `index.html` — ساختار صفحه
- `style.css` — طراحی کامل و ریسپانسیو
- `script.js` — ساعت آنالوگ/دیجیتال و تاریخ زنده
- `assets/profile.png` — تصویر پروفایل
